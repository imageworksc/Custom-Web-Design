# Custom Web Design

Repositorio base para proyectos de diseño y desarrollo web de **Image Works**.

## Estructura

```
.
├── README.md      # Este archivo
├── LICENSE        # Licencia MIT
└── .gitignore     # Archivos excluidos del control de versiones
```

## Empezar

```bash
git clone https://github.com/imageworksc/Custom-Web-Design.git
cd Custom-Web-Design
```

## Flujo de trabajo

1. Crea una rama para tu cambio: `git checkout -b feature/mi-cambio`
2. Haz commits pequeños y descriptivos.
3. Abre un Pull Request contra `main`.
